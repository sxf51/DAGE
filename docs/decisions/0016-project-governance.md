# ADR-0016：项目治理与贡献策略

- 状态：Accepted / 1.0 Freeze
- 日期：2026-07-27

## 决策

- License：MIT；
- Contribution attestation：DCO 1.1，提交使用 `Signed-off-by`；
- CLA：暂不采用；
- 发布前具备商标、安全披露、行为准则和维护者政策；
- 托管平台支持时启用 Private Vulnerability Reporting。

只有双重许可、闭源再许可、统一版权授权或明确企业/专利需求出现时，才通过新 ADR 评估 CLA。
不默认同时强制 CLA 与 DCO。

## 后果

贡献门槛较低且来源声明明确。MIT 不授予项目商标权，正式发布前必须完成名称、包管理器、域名和
目标市场商标检索。
