# ADR-0001：产品边界与语言 ABI

- 状态：Accepted
- 日期：2026-07-27

## 决策

DAGE 是 MIT 许可的小型嵌入式 DAG 运行时。内部采用 C++17，跨语言只依赖 C ABI。
DAGE 不实现 Agent 平台、数据库、网络、文件系统、认证或服务端。普通失败使用
`Result<T, Error>`；构造失败、OOM 和内部不变量使用异常；C ABI 捕获全部异常。

1.0 后 C ABI 只增量扩展，不重新编号状态码，不复用保留字段，不改变既有结构语义。
1.0 前允许以迁移说明为前提清理 API。

## 后果

语言绑定稳定且部署面小；宿主集成需要实现明确 SPI。C++ API 源码兼容可演进，但不承诺跨
编译器的二进制 ABI。
